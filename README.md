## 💻 Sobre Mí

Soy un desarrollador especializado en Backend con formación como Ingeniero Mecatrónico. Mi pasión es crear soluciones tecnológicas eficientes, escalables y bien estructuradas. Mi enfoque principal está en el desarrollo de APIs robustas, arquitecturas de microservicios y la implementación de buenas prácticas como testing, caching y seguridad. Recientemente, he comenzado a expandir mis habilidades hacia el desarrollo frontend con React, con el objetivo de crear aplicaciones móviles con React Native.

## 🌟 Proyectos Destacados

### 🚀 [Backend Test](https://github.com/VizzWard/backend_test)
Repositorio con una serie de implementaciones prácticas de conceptos avanzados en backend:
- Caching para optimización de rendimiento
- Rate limiting para protección de APIs
- Mocking para desarrollo y testing
- Tests unitarios y de integración
- Autenticación con JWT
- Arquitectura de microservicios

Cada práctica está completamente documentada para facilitar el aprendizaje y referencia.

### 🚀 [Task Manager API](https://github.com/VizzWard/task_manager)
API RESTful para la gestión de tareas implementada con buenas prácticas de desarrollo:
- Autenticación y autorización con JWT
- Rate limiting para protección contra abusos
- Documentación completa de endpoints
- Próximamente: implementación de caching, testing avanzado y más características de escalabilidad

### 📚 [PyRoadmap](https://github.com/VizzWard/PyRoadmap)
Documentación de mi trayectoria de aprendizaje en desarrollo backend y Python, basado en la ruta de aprendizaje de [roadmap.sh/backend](https://roadmap.sh/backend). Este repositorio muestra mi progresión y comprensión de conceptos clave en el desarrollo backend.
